# log_custom_printer Project Documentation

## Overview

`log_custom_printer` is a **pure Dart** logging library for CLI, server, scripts, and Flutter consumers (after startup registration).
It provides typed log objects, ANSI formatting, JSON serialization, and cache/persistence support.

## Architecture

### Design patterns

1. **Sealed class pattern**
   - `LoggerObject` is the sealed root of the log hierarchy.
   - Enables type safety and exhaustive pattern matching.

2. **Service locator / dependency injection**
   - `registerLogPrinter` and `fetchLogPrinterService` use `get_it`.
   - `LogPrinterService` centralizes filtering and dispatch.
   - `LoggerPersistenceService` wraps cache/persistence operations.

3. **Strategy pattern**
   - `LogPrinterBase` defines output strategy.
   - Built-in strategies: `LogSimplePrint`, `LogWithColorPrint`.

4. **Mixin pattern**
   - `LoggerClassMixin` gives classes simple logging methods.

## Core flow

```text
LoggerObjectBase.sendLog()
  -> fetchLogPrinterService()
  -> LogPrinterService.executePrint()
     -> LoggerPersistenceService.addLog()
     -> LogPrinterBase.printLog()
```

## Main components

- **Core:** `LoggerObject`, `LoggerObjectBase`, `LogPrinterService`, registration APIs
- **Log types:** `DebugLog`, `InfoLog`, `WarningLog`, `ErrorLog`
- **Printers:** `LogSimplePrint` and `LogWithColorPrint`
- **Configuration:** `ConfigLog(enableLog, onlyClasses)`
- **Utilities:** `LoggerClassMixin`, `DateTimeLogHelper`, `StackTraceSdk`
- **Cache layer:** `ILoggerCacheRepository`, `LoggerCacheRepositoryImpl`, `LoggerJsonList`, `LoggerCache`, `LoggerPersistenceService`

## Filtering rules

- `ConfigLog(enableLog: false)` suppresses all logs except `ErrorLog`.
- `onlyClasses` filters accepted runtime types.
- `ErrorLog` is always processed (`alwaysPrint = true`).

## JSON serialization

- Log models use `@JsonSerializable()`.
- `*.g.dart` files are generated by `build_runner`.
- `ErrorLog` serializes `StackTrace` through `StackTraceConverter`.

## Persistence and concurrency

- Memory cache grouped by `EnumLoggerType`.
- Optional file persistence under `<path>/loggerApp/logs/`.
- `FileManager` serializes writes per path to avoid race conditions.

## Recommended setup

### Development

```dart
registerLogPrinterColor(config: ConfigLog(enableLog: true));
```

### Production

```dart
registerLogPrinterSimple(config: ConfigLog(enableLog: false));
```
