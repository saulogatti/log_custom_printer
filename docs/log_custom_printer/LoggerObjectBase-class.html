LoggerObjectBase class Core - Sistema de Logging

Base contract for log objects that can be printed and serialized.

@{param message} is the log message. @{param createdAt} is the creation time of the log. @{param typeClass} is the class that emitted the log. @{param tag} is the tag attached to the log.
